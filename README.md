
# 🎓 Student Registration & Result Portal

## ✨ Features
- Student Registration
- Marks Entry
- Automatic Total & Percentage
- Pass/Fail Result
- Form Validation
- Responsive Bootstrap 5 UI
- Dynamic Result Table
